## 📖 About

CSS‑Tutorials is a collection of HTML & CSS demo files — ideal for beginners or anyone learning front‑end styling.  
Each file/tutorial helps you understand layout, styling, responsiveness, and UI basics step by step.

---

## ✅ What You’ll Find

- Simple HTML + CSS examples (buttons, cards, layout, responsive pages)  
- Flexbox / Grid layout demos  
- Basic UI component styling (navbars, footers, forms, cards)  
- Standalone files: easy to open & experiment — no build tools, no bundlers, no dependencies
